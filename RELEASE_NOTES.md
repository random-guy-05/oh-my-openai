This release packages the customized side-by-side Intel macOS application.

- Intel `x86_64` launcher and private runtime

- Simultaneous operation with the official ChatGPT app

- Dedicated Chat mode
- Atomic private-runtime updates without deleting user data

## Install

1. Download `Codex-Intel-x64.dmg`.
2. Open the DMG and drag `Codex.app` into Applications.
3. Launch Codex. If macOS blocks the ad-hoc signed build, use
   **Control-click > Open** or **Open Anyway** in Privacy & Security.

The build is ad-hoc signed and is not Apple-notarized.
